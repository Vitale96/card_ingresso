# 🌐 card_ingresso

Representa um ticket de cinema, criado com HTML e SCSS. Publicado via GitHub Pages para ser acessado por amigos e familiares.
Baseado no vídeo [Vídeo - Codeboost](https://youtu.be/jc9-whKCl5o?si=hIySK0fv8nxvTkop).
Usando Vanilla-Tilt [Vanilla-Tilt](https://micku7zu.github.io/vanilla-tilt.js/)
